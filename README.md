## About

Manager Online Marketing & CRM at ergoflix Group. I run the technical side of marketing and customer data — Salesforce platform work, the integrations between CRM, marketing automation and telephony, plus the web presence and tracking that feed them.

Ten years of web development behind it, so most of what I plan I can also build: Lightning Web Components and Apex on the CRM side, WordPress and PHP on the web side, TypeScript for tooling. Increasingly that includes LLM integrations — Claude in production workflows, and MCP servers that give agents controlled access to business systems.

**Open To** — collaboration on MCP and LLM tooling · Salesforce integration and automation topics · exchange on CRM and marketing automation architecture
